## 互联网是一组约定

浏览器和服务器并不共享内存。它们通过一条条消息协作：浏览器说“我想要什么”，服务器回答“结果是什么”。HTTP 就是这套请求/响应消息的格式约定。

<Callout type="note" title="先记住一个画面">
  客户端发起**请求**，服务器返回**响应**。请求和响应都由“起始行 + Header + 可选 Body”组成。
</Callout>

HTTP 不要求浏览器和服务器使用同一种编程语言，也不要求它们在同一台机器上。只要双方遵守消息格式，就能互操作。

## 为什么先学 HTTP

后面的 URL、方法、状态码、Header、Cookie，都是这套消息格式的不同部分。理解它们之间的关系，比记住术语更重要。
