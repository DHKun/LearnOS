## 浏览器做了什么

当你在地址栏输入网址并回车，浏览器会：

1. 解析 URL，确定协议、主机和路径。
2. 与服务器建立连接。
3. 发送请求行、Header 和可选 Body。
4. 等待响应，并根据状态码与 `Content-Type` 决定如何展示。

## 服务器做了什么

服务器收到请求后，会根据**方法 + 路径**选择处理逻辑。例如：

- `GET /users/1` → 读取用户 1。
- `POST /users` → 创建新用户。
- `DELETE /users/1` → 删除用户 1。

处理完成后，服务器返回状态码、Header 和 Body。状态码描述结果类别，Body 才承载具体资源。

<Callout type="tip" title="不要把请求和响应混在一起">
  “请求方法”描述客户端想做什么；“响应状态码”描述服务器处理结果。两者不是同一层概念。
</Callout>
