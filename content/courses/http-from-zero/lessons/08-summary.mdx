## 一张表回顾

| 概念 | 关键问题 | 例子 |
| --- | --- | --- |
| URL | 资源在哪里？ | `/users/1` |
| 方法 | 想做什么？ | `GET` / `POST` |
| 状态码 | 结果类别？ | `200` / `404` |
| Header | 元信息是什么？ | `Content-Type` / `Cookie` |
| Body | 具体内容是什么？ | JSON、HTML |

## 推荐的调试顺序

1. 先看请求行：方法、目标、协议版本是否正确。
2. 再看 Header：Host、Accept、Content-Type、Cookie 是否合理。
3. 看状态码：2xx / 4xx / 5xx。
4. 最后看 Body 和 Content-Type 是否匹配。
