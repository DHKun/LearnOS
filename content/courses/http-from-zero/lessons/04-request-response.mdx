## 一条请求的解剖

```http
GET /users/1 HTTP/1.1
Host: example.test
Accept: application/json
```

- 请求行：方法 `GET`、目标 `/users/1`、协议版本。
- Header：`Host` 告诉服务器要访问哪个站点，`Accept` 表达期望的响应类型。
- Body：GET 通常没有 Body。

再看响应：

```http
HTTP/1.1 200 OK
Content-Type: application/json

{"id":1,"name":"小明"}
```
