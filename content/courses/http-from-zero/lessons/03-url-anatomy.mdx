## URL 不是一整块字符串

把它拆开看：

```text
https://example.test:8443/users/1?page=2&sort=name
└─┬─┘   └────┬─────┘└┬┘└──┬──┘└──────┬──────┘
协议        主机      端口 路径        查询参数
```

## 路径与查询参数

- **路径** `/users/1` 描述资源层级。
- **查询参数** `?page=2&sort=name` 调整资源的表示或筛选方式。

`/users/1` 和 `/users?page=1` 都可能返回用户列表/用户，但语义不同：前者是单个资源，后者是集合的筛选视图。
