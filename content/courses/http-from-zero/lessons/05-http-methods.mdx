## 方法表达意图

| 方法 | 典型语义 | 幂等 | 安全 |
| --- | --- | --- | --- |
| GET | 读取资源 | 是 | 是 |
| POST | 创建/处理 | 否 | 否 |
| PUT | 整体替换 | 是 | 否 |
| DELETE | 删除资源 | 是 | 否 |

“幂等”描述重复执行的结果是否与执行一次相同；“安全”描述是否应改变服务器状态。

<Callout type="warning" title="方法不是装饰">
  用 GET 执行删除、用 POST 读取数据，可能破坏缓存、重试和权限判断的语义。
</Callout>
