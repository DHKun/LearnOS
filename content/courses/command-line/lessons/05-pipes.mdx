## 周报里的访问排行

周报最后一节要写今天访问最多的 3 个 IP。日志有两千多行，没有哪个命令能一步算出“访问最多的 IP”。但几个小命令接起来就可以。

## 管道

`|` 叫**管道**：把左边命令的输出，直接交给右边的命令当输入。

```bash
grep '" 500 ' access.log | wc -l       # 有多少条 500
grep loans access.log | tail -n 5      # 最近 5 条借书请求
```

右边的命令没写文件名时，就读管道传过来的内容。

## 取列、排序、计数

| 命令 | 作用 |
| --- | --- |
| `cut -d ' ' -f 1` | 按空格切开，取第 1 列 |
| `awk '{print $1}'` | 同样是取第 1 列，连续多个空格也能正确处理 |
| `sort` | 按字母排序；`-n` 按数字，`-r` 倒序 |
| `uniq -c` | 把**相邻**的相同行合并，并在前面写上有几行 |
| `head -n 3` | 只要前 3 行 |

## 把结果存进文件

| 写法 | 作用 |
| --- | --- |
| `命令 > 文件` | 输出写进文件；文件原来有内容的话**先清空** |
| `命令 >> 文件` | 输出追加到文件末尾，原来的内容不动 |
| `命令 2> 文件` | 只把报错写进文件 |
| `命令 2>/dev/null` | 把报错扔掉；`/dev/null` 是个“什么都吞掉”的文件 |

`>` 会在命令运行**之前**就把文件清空，所以 `sort a.txt > a.txt` 会得到一个空文件。往已有的文件里加内容，一定用 `>>`。
