## 乱成一团的上传目录

读者上传的封面图和 PDF 全堆在一个目录里，混着上传失败留下的临时文件。这一章你要用命令把它们分门别类放好，而且一个该留的文件都不能丢。

## 看清楚再动手

```bash
ls -l        # 长格式：权限、主人、大小、修改时间
ls -a        # 连以 . 开头的隐藏文件一起列出
ls -la old   # 看某个子目录
cat a.txt    # 看文件内容
```

名字以 `.` 开头的文件是**隐藏文件**，普通的 `ls` 不显示它们。配置文件常常是隐藏的，比如家目录里的 `.bashrc`。

## 新建、复制、移动、删除

| 命令 | 作用 |
| --- | --- |
| `mkdir images` | 新建目录；`mkdir -p a/b/c` 连中间的目录一起建 |
| `cp a.txt b.txt` | 复制文件；复制目录要加 `-r` |
| `mv a.txt docs/` | 移动到目录里；`mv a.txt b.txt` 是改名 |
| `rm a.txt` | 删除文件；删除目录要加 `-r` |
| `rmdir old` | 删除**空**目录，里面有东西会拒绝 |

`mv` 和 `cp` 的最后一个参数是目标。目标是已有的目录时，文件会放进去、名字不变；不是目录时，就当作新名字。

## 通配符

`*` 匹配任意多个字符，`?` 匹配一个字符。`rm *.tmp` 删掉当前目录下所有 .tmp 文件。两点要注意：

- `*` **不匹配隐藏文件**，`rm *` 不会删掉 `.htaccess`。
- `*` **只看一层**，`*.tmp` 不包括子目录里的 .tmp。

先用 `ls *.tmp` 看看会匹配到哪些文件，确认无误再把 `ls` 换成 `rm`。
