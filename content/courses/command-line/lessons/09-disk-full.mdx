## 看磁盘的三个命令

```bash
df -h                          # 每块磁盘用了多少、还剩多少
du -sh /var/*                  # 每个目录一共占多大
find / -size +1G 2>/dev/null   # 找出大于 1 GB 的文件
```

`-h` 是“给人看的”单位（K、M、G）。`du` 和 `find` 遇到没权限的目录会报 `Permission denied`，用 `2>/dev/null` 把这些报错扔掉，结果更清楚。

`du` 适合一层一层往下找：先看 `/var/*`，哪个大就进哪个继续看。

## 处理故障的顺序

1. **看症状**：网站怎么了？`curl -I localhost` 返回什么？
2. **找原因**：`df -h` 满了没有？是谁占的？`systemctl status` 里写了什么？
3. **想后果**：要删的东西还有没有用？还有没有程序在用它？
4. **动手**，然后**验证**：再看一次 `df -h` 和 `curl`。

先查清楚再动手。凌晨三点手一抖删错了东西，比磁盘满更难收拾。
