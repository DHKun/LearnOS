## 一个让人吃惊的等式

在几乎所有编程语言里：

```text
0.1 + 0.2 = 0.30000000000000004
0.1 + 0.2 == 0.3  →  false
```

这不是 bug，而是小数在二进制里的存法决定的。

## 浮点数只是近似值

计算机里最常用的小数类型叫**浮点数**（float / double）。它能表示极大和极小的数，代价是很多十进制小数只能存成近似值：0.1、0.2、0.7 都是。

近似值平时看不出来，但会在三种地方出问题：

1. **比较**：`0.7 + 0.1 >= 0.8` 的结果是 false，“余额正好够”被判成“余额不足”；
2. **累加**：成千上万笔交易加起来，误差可能积累到肉眼可见；
3. **显示**：直接把结果显示出来，会看到一长串小数。

## 和钱打交道的三条规矩

- **用整数存最小单位**：1.99 元存成 199 分。
- **在规定的环节舍入**：发票上每一笔都是精确到分的金额，系统也要逐笔舍入，否则合计会和发票对不上。
- **只在显示时格式化**：存的是整数，显示时才写成两位小数。
