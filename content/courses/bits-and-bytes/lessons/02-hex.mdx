## 一串 0 和 1 太难读了

`11010110` 是多少？要数清楚每一位并不容易，写错一位更是常有的事。程序员几乎从不直接写二进制，而是写成十六进制：`D6`。

## 二进制怎么换成十进制

每一位都有自己的“分量”，从右往左依次是 1、2、4、8、16、32、64、128。把是 1 的位的分量加起来：

```text
1 1 0 1 0 1 1 0
128 + 64 + 16 + 4 + 2 = 214
```

## 十六进制：每 4 位一段

<ConceptPlayer conceptId="bits-and-bytes/hex" blockId="hex" />

4 个比特正好是 0～15 共 16 种状态，一个十六进制数字就能表示它：`0`～`9`，再加 `A`(10)、`B`(11)、`C`(12)、`D`(13)、`E`(14)、`F`(15)。所以：

- 一个字节永远写成**两位**十六进制，比如 `00`、`7F`、`FF`；
- 写成十六进制的数常带上 `0x` 前缀，比如 `0xD6`，以免和十进制混淆。

你会在很多地方见到它：网页颜色 `#FF6600`、网卡地址 `3C:22:FB:…`、错误代码 `0x80070005`。

## 小结

- 二进制每一位的分量是 2 的幂；十六进制把每 4 位写成一个数字。
- 一个字节 = 两位十六进制。看到 `0x` 或成对的 `0`～`F`，就想到“这是在说字节”。
- 想在不影响其他灯的情况下多点亮一颗，就是把那一位“置 1”，其他位保持原样。
