# 0 和 1 的世界：计算机怎么表示信息（`bits-and-bytes`）

**版本**：`1.0.0` · **格式**：Manifest `schemaVersion: 3` · **制作方式**：按 `.claude/skills/learnos-course-authoring/` 的流程制作

## 设计思路

**一个世界**：一台模拟的“字节机”。每个实验都在看一串字节，并决定怎么读它。整门课只有一个核心认识：**同一串字节，换一种读法，就是另一样东西。**

**一个比喻**：一排开关 + 一本密码本。比特是开关；编码、数据类型、文件格式都是事先约定的密码本；乱码、溢出、文件打不开，都是拿错了密码本。

**知识前后衔接**：第 12 章的综合任务同时用到字节序（第 3 章）、整数溢出（第 4 章）、UTF-8 与 GBK（第 6、7 章）、文件签名（第 10 章）和校验和（第 11 章）。

## 目录

```text

activities/labs.tsx     十一个实验组件
```

实验外壳与动画基础组件来自平台的 `components/education/lab-kit.tsx` 和 `scene-kit.tsx`。

## 判分与确定性

- 章节是否通过只由 `validators.ts` 在服务端重新计算决定，浏览器里的结果只用于即时反馈。
- 不依赖运行环境的文本编码支持：UTF-8 编解码是自己实现的；GBK 只收录本课用到的约 20 个字，用查表实现。这样浏览器和服务端读同一串字节，结果总是一样。
- 第 5 章的浮点误差就是 JavaScript 真实的 IEEE 754 双精度运算，各平台结果一致。
- 第 9 章的图片体积是一个写明假设的教学模型（各格式的固定压缩比，见章节正文），不是真实的编码器。
