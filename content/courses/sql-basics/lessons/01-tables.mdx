## 网站背后的那本账

在《HTTP 实战》里，你请求 `/books/7`，服务器就回了一本书的信息。那本书的书名、作者、还剩几册，都存在**数据库**里。网站的每一次借书、还书、注册，最后都是在数据库里加一行或者改一行。

这门课要打开 library.test 的数据库，看看里面装的是什么，学会自己去查、去改，而且改得安全。

## 表、行、列

数据库里的数据放在一张张**表**里。library.test 有三张：

| 表 | 每一行是 | 主要的列 |
| --- | --- | --- |
| `books` | 一本书 | `id`、`title`、`author`、`added`（上架日期）、`copies`（馆藏册数）、`status` |
| `readers` | 一位读者 | `id`、`name`、`email`、`joined` |
| `loans` | 一次借书 | `id`、`book_id`、`reader_id`、`borrowed`、`due`（应还日期）、`returned`（归还日期） |

每一列都有类型：数字、文字、日期或真假。没有值的格子是 **NULL**，比如还没还的书，`returned` 就是 NULL。

## 主键和外键

- **主键**：每一行都有一个独一无二、不能为空的编号，这里都是 `id`。有两位读者都叫王芳，靠编号 3 和 11 才分得清。
- **外键**：`loans.reader_id` 写的是“这次是哪位读者借的”，它必须是 `readers` 里真实存在的某个 `id`。数据库会拒绝写入一个不存在的编号，也会拒绝删掉还被借阅记录引用着的读者。

借阅表不抄读者的姓名和邮箱，只记编号。读者改了邮箱，只要改 `readers` 里的一行。

## SQL

和数据库打交道用的语言叫 **SQL**。下一章开始写的第一条语句是：

```sql
SELECT * FROM books;
```

意思是“把 books 表里所有的列、所有的行都给我”。SQL 的关键字不分大小写，习惯上写成大写；每条语句以分号结尾。
