## 逾期未还的书

馆长要给逾期没还书的读者发提醒。哪些借阅算逾期？已经过了应还日期，而且到今天还没还。这一章学会把这些行挑出来。

## SELECT：要哪些列

```sql
SELECT title, author FROM books;     -- 只要书名和作者
SELECT * FROM loans;                 -- 所有列
SELECT * FROM loans LIMIT 10;        -- 先看前 10 行，摸清长什么样
```

## WHERE：要哪些行

```sql
SELECT * FROM books WHERE author = '刘慈欣';
SELECT * FROM books WHERE copies >= 2 AND category = '文学';
SELECT * FROM books WHERE title LIKE '三体%';   -- % 匹配任意多个字
SELECT * FROM loans WHERE borrowed BETWEEN '2026-10-01' AND '2026-10-31';
```

- 文字和日期用**单引号**括起来；数字不用。
- 比较：`=`、`<>`（不等于）、`<`、`>`、`<=`、`>=`。
- 组合条件：`AND`、`OR`、`NOT`。`AND` 比 `OR` 先算，拿不准就加括号。
- `CURRENT_DATE` 是今天的日期。

## NULL：不是 0，也不是空白

NULL 表示“没有值”或“不知道”。拿任何值和 NULL 比较，结果都是“不知道”，连 `NULL = NULL` 也是。WHERE 只留下结果为“真”的行，“不知道”的行会被丢掉。

所以判断空值要用专门的写法：

```sql
SELECT * FROM loans WHERE returned IS NULL;       -- 还没还的
SELECT * FROM readers WHERE email IS NOT NULL;    -- 填了邮箱的
```
