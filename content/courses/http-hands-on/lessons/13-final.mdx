## 回顾：十个关键判断

1. HTTP 只管「要什么、结果如何」；DNS 找地址，TLS 保护通道。
2. 没有状态码（`(failed)`）的失败，发生在 HTTP 之前。
3. URL 的片段 `#…` 不发给服务器；路径和查询写进请求行。
4. 请求和响应的结构相同：起始行、头部、空行、可选的正文。
5. 状态码首位数字说明谁该行动，细节在 `Location`、`Allow`、`Retry-After` 等头部里。
6. PUT 整体替换，PATCH 局部修改；只有幂等的请求可以放心重试。
7. `Accept` 问的是想要什么格式，`Content-Type` 说明正文实际是什么格式。
8. Cookie 由浏览器按 `Path`、`Secure`、`SameSite` 自动附上，`HttpOnly` 挡住脚本读取；服务器仍要查表认人。
9. 401 是不知道你是谁，403 是知道你是谁但不允许。
10. `max-age` 决定多久内不发请求，ETag 和 304 决定问了之后要不要重传；`no-cache` 表示每次先验证，`no-store` 才是不存。
