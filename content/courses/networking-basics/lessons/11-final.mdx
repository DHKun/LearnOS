## 回顾：十个关键判断

1. 数据被拆成小包，每台路由器只看目的地址决定下一站，没有谁知道完整路线。
2. 子网掩码决定网段；同网段直接送，不同网段交给默认网关。
3. 网络地址和广播地址不能分给设备；手动设置的地址要避开已用地址和 DHCP 地址池。
4. ARP 在局域网里把 IP 换成 MAC；两台设备用同一个 IP 就会时好时坏。
5. 路由按最长前缀匹配；默认路由兜底；私有地址不能走向互联网。
6. DNS 有层层缓存和 hosts 文件；对照权威服务器的答案，就能分清是缓存、hosts 还是记录本身的问题。
7. IP 找机器，端口找程序；TCP 和 UDP 各有一套端口。
8. 超时多半是被挡或不通，“连接被拒绝”说明路通、端口没人听。
9. NAT 让全家共用一个公网地址；端口转发要配对协议，目标设备的地址要固定。
10. traceroute 里中间某跳不回话或回得慢不算故障，要看从哪一跳开始后面全断了。
