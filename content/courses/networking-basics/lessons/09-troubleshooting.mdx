## 网站打不开，是谁的问题

是我家的网？运营商的？还是网站自己挂了？两个小工具能帮你一段一段地排查：`ping` 和 `traceroute`（Windows 上叫 `tracert`）。

## ping：它在吗，多远

`ping 198.51.100.10` 会发几个小包给对方，看它回不回、多久回：

- 有回复：路是通的，后面的数字是来回一趟的时间；
- 请求超时：对方没回。可能是路不通，也可能是对方设置了不回应 ping。

**由近到远地 ping**：先 ping 自家路由器，再 ping 运营商网关，再 ping 目标。哪一段开始不通，问题就在哪一段附近。

## traceroute：一路经过了谁

traceroute 利用 TTL 一跳一跳地把路线探出来。读结果时要注意两种“看起来吓人但正常”的情况：

| 看到的 | 意思 |
| --- | --- |
| 中间某一跳 `* * *`，后面的跳正常 | 这台路由器不回应探测包，但照常转发，**不是故障** |
| 中间某一跳延迟很高，后面的跳又恢复正常 | 这台路由器回应探测包慢，不代表它转发慢，**不是瓶颈** |
| 从某一跳开始，**后面全是** `* * *` | 真正断开的位置大概在这附近 |
