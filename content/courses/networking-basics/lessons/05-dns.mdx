## 名字和地址

人记得住 library.test，记不住 198.51.100.10。**DNS** 就是互联网的查号台：把名字换成 IP 地址。上一门课学过的 HTTP 请求，第一步就是做这件事。

## 一次查询经过谁

1. **本机**：浏览器和系统的缓存，还有 **hosts 文件**（写死的“名字 → 地址”对照表，优先级最高）。
2. **递归 DNS**：运营商、公司或公共的 DNS 服务器，替你去问。
3. **根 → 顶级域 → 权威**：递归 DNS 从根服务器开始，一级级问到 library.test 自己的**权威 DNS 服务器**。
4. 权威服务器给出答案：一条 **A 记录**，附带 **TTL**（可以缓存多少秒）。

## 改了记录，为什么有人还看到旧的

网站搬到新服务器后，管理员改了 A 记录。可是在 TTL 到期之前，各处缓存里还存着旧地址。所以“改了 DNS 要等一会儿才生效”。

## 用对照法排查

拿到一份“解析出来的地址”，先和**权威服务器的答案**对照：

| 权威服务器 | 你拿到的 | 问题在哪 |
| --- | --- | --- |
| 新地址 | 旧地址 | 缓存未过期，或 hosts 文件写死了 |
| 旧地址 / 错地址 | 同样的 | 记录本身填错了 |
| “不存在” | “不存在” | 域名拼错了 |
| — | 超时 | DNS 服务器本身连不上 |
| 新地址 | 新地址 | DNS 没问题，问题在别处 |
