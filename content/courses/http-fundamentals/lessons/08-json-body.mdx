## Body 是 HTTP 消息承载的数据

不是所有请求都带 Body。GET 通常用于读取，不依赖请求正文；POST、PUT、PATCH 则常在 Body 中携带表单或 JSON 数据。

JSON（JavaScript Object Notation）是一种常见的数据交换表示格式，能描述对象、数组、字符串、数字、布尔值和 `null`。例如：

```json
{
  "title": "第一次成功发送 POST",
  "tags": ["http", "learning"],
  "published": false
}
```

一份合法 JSON 有自己的语法规则：字段名称和字符串使用双引号，没有 JavaScript 注释，末尾不允许多余逗号。

## 三个错误，各有不同原因

假设这个教学服务器支持 `POST /api/notes` 创建便签：

1. 请求的 `Content-Type` 不是 `application/json`：返回模拟 `415`，因为服务器不接受当前媒体类型。
2. Body 不是合法 JSON：返回模拟 `400`，因为无法解析结构。
3. JSON 合法但缺少非空的 `title`：返回模拟 `400`，因为不符合这门课设定的字段校验规则。
4. 字段与格式都符合要求：返回 `201 Created`，并附带新资源位置。

这些状态码是本课虚拟服务的约定；真实 API 可能使用更细的 `422` 或其他错误格式。
