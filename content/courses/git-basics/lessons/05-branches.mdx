## 开发到一半的紧急修复

你要做一个好几天才能完成的搜索功能。第一天刚开工，首页就发现一个要马上修的错误。如果搜索做了一半的代码已经混在 main 里，修复就没法单独上线。

## 分支

**分支**是一张会移动的标签，贴在某个提交上。`main` 通常是可以随时发布的那条线。新功能在自己的分支上做，做完再合回 main。

```bash
git branch                     # 列出分支，* 是当前所在的
git switch -c feature/search   # 新建分支并切过去
git switch main                # 切回 main
git branch -d feature/search   # 删除已经合并的分支
```

旧教程里常见的 `git checkout -b 名字` 和 `git checkout 名字`，作用和 `switch` 一样。

## 切换分支时发生了什么

`git switch main` 会把工作区换成 main 最新提交的样子：只在别的分支上提交过的文件会从工作区里“消失”，切回去又会出现。

还没提交的改动会跟着你一起切换；如果它会被目标分支的内容覆盖，Git 会拒绝切换，提示你先提交。
