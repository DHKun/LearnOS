## 结果对，但是太慢

三段程序的结果都对，就是太慢。它们做的计算量都不大，慢在读内存：CPU 每次都在等数据从内存里搬过来。

## 存储的层级

| 位置 | 读一次大约要 |
| --- | --- |
| 寄存器 | 1 个周期 |
| 缓存 | 几个周期 |
| 内存 | 一两百个周期（格子机里简化成 20） |
| SSD / 硬盘 | 几万到几百万个周期 |

**缓存**是 CPU 旁边一小块很快的存储，放最近用过的数据。要的数据在缓存里叫**命中**，不在叫**未命中**：只好去内存里取，而且一次搬回一整“行”挨着的数据。

## 局部性

缓存起作用，靠的是程序的两个习惯：

- **空间局部性**：用了一个格子，很可能马上要用它旁边的；
- **时间局部性**：刚用过的，很可能马上还要再用。

所以按顺序访问、把一起用的数据放在一起，会快很多。一张表格按行存放，就该按行遍历；要反复读的那一列数据，最好单独挨着存放。
