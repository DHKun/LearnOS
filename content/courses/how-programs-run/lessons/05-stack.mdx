## 跑飞了的函数

一段程序调用两次函数 `double`，本该打印 8 和 14，结果一个数也没打印，还报错说栈满了。要明白为什么，得先看看函数调用是怎么“记住回去的路”的。

## 栈

内存的最后一段被当作**栈**来用，格子机的栈从地址 63 往下长。栈只能从顶上放、从顶上拿：

| 指令 | 作用 |
| --- | --- |
| `PUSH R1` | 把 R1 放到栈顶 |
| `POP R1` | 从栈顶拿一个数放进 R1 |
| `CALL 标签` | 把“下一条指令的位置”（返回地址）放到栈顶，然后跳到标签 |
| `RET` | 从栈顶拿出返回地址，跳回去 |

`SP`（栈指针）记着栈顶在哪。

## 函数里用到的寄存器要保存

函数会改动寄存器。调用它的人可能还要用原来的值，所以函数开头常常先 `PUSH` 保存，结束前再 `POP` 恢复。**每个 PUSH 都要有对应的 POP。** 少一个，`RET` 从栈顶拿到的就不是返回地址。
