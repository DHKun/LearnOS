## 少加了一个数的循环

同事写了一段程序算 1 + 2 + … + N，自己试了 N = 10，结果是 45，以为对了。正确答案是 55。机器里没有“循环”这种指令，循环是用比较和跳转拼出来的，边界最容易出错。

## 比较和条件跳转

`CMP R0, R1` 比较 R0 和 R1，把结果记在两个**标志位**里：

- **Z**（zero）：两者相等时为 1；
- **N**（negative）：R0 比 R1 小时为 1。

条件跳转看标志位决定跳不跳：

| 指令 | 什么时候跳 |
| --- | --- |
| `JMP 标签` | 总是跳 |
| `JZ` / `JNZ` | 相等 / 不相等 |
| `JLT` / `JGE` | 小于 / 大于等于 |

`ADD` 和 `SUB` 也会更新标志位：结果是 0 时 Z 为 1。标签写在行首，后面加冒号：`loop:`。

## 用跳转拼出循环

“从 N 倒数到 1，每个数打印一次”可以写成：

```text
loop: CMP R0, 0    ; R0 里是当前的数
      JZ done      ; 已经数到 0，结束
      OUT R0
      SUB R0, 1
      JMP loop
done: HALT
```

这是**先判断、再做**的写法：N = 0 时一圈都不会走。如果把判断放到最后（**先做、再判断**），至少会走一圈，N = 0 时就会多打印一次。
