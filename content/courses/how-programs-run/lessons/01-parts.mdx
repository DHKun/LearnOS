## 双击之后发生了什么

你双击一个图标，程序就开始运行了。这一下背后，硬盘、内存、CPU 和操作系统都动了起来。《0 和 1 的世界》讲了计算机里装的是什么，这门课讲这些 0 和 1 是怎么被**执行**的。

## 三样东西

| 部件 | 做什么 | 特点 |
| --- | --- | --- |
| **CPU** | 一条一条地执行指令 | 很快；里面有几个**寄存器**，放正在算的数 |
| **内存** | 放正在运行的程序和它的数据 | 比硬盘快得多，一断电就清空 |
| **硬盘 / SSD** | 长期保存文件 | 存得多、存得久，但慢 |

程序平时是硬盘上的一个文件。运行时，操作系统先把它搬进内存，CPU 再从内存里一条一条取指令来执行。

## 格子机

真实的 CPU 有几百条指令、几十亿个内存格子，一开始太复杂。这门课用一台简化的模拟计算机**格子机**：

- 4 个寄存器：`R0`、`R1`、`R2`、`R3`；
- 64 格内存，地址是 0～63，每格放一个整数；
- 十几条指令，比如 `LOAD`（从内存读到寄存器）、`ADD`（加）、`STORE`（从寄存器写回内存）、`JMP`（跳转）。

指令写成这样，分号后面是注释：

```text
LOAD R0, [10]   ; 把地址 10 里的数读到 R0
ADD R0, 5       ; R0 加 5
STORE R0, [20]  ; 把 R0 写到地址 20
HALT            ; 停下
```

真实的 CPU 指令（汇编语言）长得和这个很像。你平时写的 Python、JavaScript，最后也都会变成这样一条一条的指令。
