## 回顾：十个关键判断

1. 程序运行前要从硬盘搬进内存；CPU 只直接和寄存器、内存打交道。
2. CPU 不停地取指、译码、执行，程序计数器 PC 指着下一条指令。
3. 寄存器的值变了，内存不会跟着变：要 STORE 才写进去，要 LOAD 才读出来。
4. 循环是比较加条件跳转；测试时专门试一圈都不走、只走一圈、最后一圈。
5. 数组是一排挨着的格子，指针存的是地址；机器不检查边界，越界写入会悄悄写坏旁边的数据。
6. CALL 把返回地址压栈，RET 取回；函数里的 PUSH 和 POP 必须配对。
7. 越靠近 CPU 的存储越快越小：寄存器、缓存、内存、硬盘。
8. 缓存一次搬一整行，按顺序访问、把一起用的数据放在一起更快。
9. 进程是运行中的程序；操作系统通过上下文切换让多个进程轮流使用 CPU。
10. 调度要在响应速度、吞吐量和切换开销之间取舍，时间片不能太大也不能太小。
